# VDRO 1.3.0

- 顶部切换“音频剪辑”和“音频调整”，设置入口共用同一个按钮。
- 音频剪辑界面重新设计，保留左侧素材库及结果栏内输出设置。
- 新增纯音频调整：音高、音量、渐入渐出、共振峰保留和削波保护。
- 实时试听采用 Rubber Band R3 AudioWorklet/WASM，支持音高标记及平滑过渡、波形缩放和标记吸附。
- 音频调整启动时预加载；修复数字标记点击与显示层级。
- 支持 WAV / MP3 / M4A / FLAC，输出格式和音质可在页面选择。
- 两页共用输出默认值、采样率、声道、保存方式、目录及文件命名规则。
- 设置新增“音频调整”：共振峰、削波保护、标记吸附默认开关与吸附距离。
