# VDRO 1.3.2

- 新增项目首页，支持创建、打开项目、恢复未命名草稿，以及查看最近动态和快捷键。
- 新增现代界面与启动动画，支持在设置中切换新旧界面，顶栏整合导航和设置入口。
- 音频调整融合单轨编辑与多轨混音，支持拖入素材、移动片段、边缘裁剪、对齐吸附和实时混音试听。
- 增加选择、分割、撤销重做、删除、音高标记和倒放工具，以及片段右键菜单。
- 项目独立保存轨道、裁剪范围、标记、参数与结果记录，支持丢失素材重试和重新定位。
- 修复快速切换素材时波形与当前文件错位、清理临时文件后结果失效、输入时间时意外改变淡入淡出等问题。
- 分割保留原有渐入渐出曲线，静音轨道的试听与导出结束时间保持一致，重开项目后可复用相同的生成结果。
- 优化 PCM WAV 和压缩素材的试听准备，跳过静音或忽略轨道的准备工作。
- 默认输出 WAV，波形缩放上限为 32 倍，每个混音最多支持 64 个片段。
- 同步中英文、字号、缩放和主题设置，整理使用说明与第三方许可文档。
