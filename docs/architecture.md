# 当前结构与本轮改进

本轮改进布局、职责划分、数据保存和设置来源，不新增测试框架或持续回归体系。这些改进现已纳入 1.2.5 安装包。

## 设置

- `src/shared/defaults.ts`：默认设置的唯一来源，包括快捷键。
- `src/shared/settings.ts`：纯设置校验，两端共用；处理格式、范围及持久化依赖。
- `src/main/settings.ts`：只负责设置文件的读写，保留旧导出以兼容调用。
- 界面设置更新不再在 React 状态更新函数内写文件，由设置持久化逻辑统一处理。

## 布局及播放

- `src/renderer/src/layout/panelLayout.ts`：折叠尺寸、最小高度、布局读取与边界模型，同时生成布局 CSS 变量。
- `src/renderer/src/layout/usePanelLayout.ts`：布局状态、折叠动作、拖动生命周期、窗口缩小时的高度约束与布局持久化。
- `src/renderer/src/playback/useMediaPreview.ts`：媒体播放事件绑定及 Canvas 预览绘制、清理。
- App 负责组合界面及操作；波形编辑和素材列表仍保留在 App，后续可按独立职责继续拆分。
- 移除布局中没有独立意义的固定 timelineHeight 保存字段；旧布局仍可读取。
- 恢复设置和布局前不写默认布局；关闭布局恢复时不覆盖已保存的布局。

## 保存与素材关联

- `src/main/files.ts`：完成同目录临时文件后替换目标。替换失败时保留旧目标，清理临时文件。
- 设置、素材库和提取记录按目标路径串行保存，写入内容是调用时的快照，避免并发争用和写入顺序颠倒。
- 窗口状态使用同步临时文件替换；音频导出不再先删除旧目标。
- 对话框另存先复制到临时文件再替换；固定目录保存采用排他创建并自动递增文件名，避免并发覆盖。
- 保存设置、素材库和片段记录失败会在界面显示错误。
- 新片段记录包含完整 sourceFilePath，重启后按路径关联；不依赖会重新生成的媒体 ID 或文件名。
- 旧片段仅在同名素材唯一时迁移到完整路径。同名有歧义时保持未绑定，用户需移除同名歧义后重试，不自动猜测。

本轮检查包括类型检查、构建、并发保存、模拟目标被锁时保留旧文件、同名素材关联、四种音频提取，以及隔离窗口内两种缩放下的布局拖动和视频播放。
