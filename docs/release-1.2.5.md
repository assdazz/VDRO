# VDRO 1.2.5

- 安装升级时检查新旧目录内运行中的应用及媒体任务，提示保存退出后重试，不强制终止进程。

- 增加自动硬件优先和 CPU 软件视频解码模式，支持系统选择 NVIDIA / AMD / Intel 可用硬件路径，重启后应用。
- 显示当前视频实际解码器、显卡信息、累计帧数及掉帧数。多显卡品牌不猜测实际设备。
- 原生视频预览减少逐帧 Canvas 绘制；手动预览使用受限尺寸 Canvas。
- 修复折叠预览后面板遮挡、底部拖动条超出窗口的问题。
- 统一布局模型，拆分面板拖动和媒体预览逻辑。
- 默认设置、快捷键及校验共用一份定义。
- 设置和记录采用串行临时文件替换，覆盖导出失败保留旧目标。
- 片段按完整源文件路径关联，旧记录存在同名歧义时不自动绑定。
- 保留 1.2.2 的启动优化、波形框选改进及白天主题移除。
