# VDRO 1.2.2

- 压缩首屏脚本与样式，设置面板改为按需加载。
- 在用户数据目录的 `startup.log` 中记录启动各阶段耗时。
- 改进波形按住左键拖动框选：支持双向选择、已有选区内重新框选，并修正放大后的预览坐标。
- 补充框选时的指针捕获及操作中断处理，保留单击定位和两端手柄微调。
- 移除白天主题及其样式、选项和翻译；已有设置自动回退到深色。
