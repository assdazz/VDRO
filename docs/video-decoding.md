# 视频解码与预览

设置 → 预览 → 视频解码模式：

- 自动（硬件优先）：使用 Electron/Chromium 的平台解码路径，支持 NVIDIA、AMD、Intel 具备相应编码支持的显卡。由系统和驱动选择设备，不提供强制指定品牌的虚假选项。不支持的编码会尝试软件解码。
- 软件解码（CPU）：关闭视频硬件解码，保留窗口与波形的 GPU 合成。适用于排查视频黑屏或驱动问题。

修改后重启生效。设置界面显示本次进程实际采用的模式；存在待应用的修改时，可保存设置并重启。重启前请保存要保留的片段。

诊断信息包括显卡、平台硬件视频解码可用性、当前媒体累计帧数及掉帧数。硬件解码可用不等于当前视频正在硬解；不能由此推断所有编码、位深或分辨率都受支持。GPU 品牌不是视频格式兼容性的保证。

当前视频解码器通过 Chromium Media 诊断读取，按播放 URL 匹配，排除其他音频播放器及旧素材。Windows D3D11/D3D12/DXVA 解码器标记为硬件，已知 FFmpeg/VPx/Dav1d/AOM 解码器标记为软件；未知解码器或诊断断开时显示尚未确认，不根据可用性猜测。DevTools 占用调试连接时，播放继续，诊断可能不可用。

当前视频确认硬解且仅检测到一个硬件显卡品牌时，自动选项显示例如“自动选择（NVIDIA）”。品牌依据已检测到的唯一硬件品牌推定，不是逐视频解码设备的直接查询；多品牌显卡时不显示具体品牌。自动模式落到已知软件解码器时显示“自动选择（CPU）”。

“173 / 0”表示当前媒体累计处理 173 帧（含显示和丢弃），播放器报告丢弃 0 帧；它不证明正在硬件解码。

默认的原生预览直接显示 video 元素，避免逐帧复制到 Canvas。手动选择预览分辨率或帧率时使用 Canvas，绘制尺寸以预览面板及源视频尺寸为上限；预览菜单中可切回原生预览。预览尺寸和帧率设置不改变导出音频质量。

波形生成、音频提取仍使用 CPU。硬件解码改善视频播放负载，不保证软件启动更快。

## 验证记录

- 类型检查和生产构建通过。
- 旧设置和未知 decoderMode 默认回退到 auto。
- 隔离数据目录中验证自动及软件模式，H.264/AAC 1280×720 样本播放成功，原生预览无 Canvas。
- 本机 RTX 3070：自动模式 video_decode=enabled；软件模式 video_decode=disabled_software。两次短样本各记录到 32 帧、0 掉帧。
- 已检查两种模式下的设置面板截图。AMD、Intel 及其他编码需要在相应设备上验证；本次未声称已完成跨厂商实测。

此功能已纳入 1.2.5 安装包；历史 1.2.2 安装包不包含此功能。
