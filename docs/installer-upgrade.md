# 覆盖升级流程

安装器继续沿用同一个 appId、每用户安装、原有安装目录读取和 NSIS 卸载旧版本机制，不改变用户数据目录。没有增加额外向导页面。

## 运行中进程保护

安装前读取目标安装目录以及注册表记录的旧安装目录，检查其中的 VDRO.exe、ffmpeg.exe 和 ffprobe.exe。目录比较忽略大小写并包含目录分隔符，避免把 VDRO-Other 等相似目录当成目标。

发现应用或媒体任务运行时，交互安装提示用户保存片段、退出旧版并重试；取消则退出。安装器不再执行默认的强制终止流程。无法读取进程信息时停止并提示重试，不猜测。

静默安装不会弹出等待提示：运行中进程返回 1618，无法查询返回 1603。交互取消返回 1602。进程检查脚本只读，不删除文件或修改设置；如果系统策略禁止 PowerShell/CIM 进程查询，需要先解决该环境限制，不能跳过检查继续覆盖。

改变安装目录时旧目录也会检查，避免只检查新目录而漏掉正在运行的旧版。新卸载程序也使用相同检查；已发布的旧卸载程序无法事后修改，因此新版安装器在调用旧卸载程序前先完成保护检查。

## 验证

- 无进程、目标目录进程、旧目录媒体任务、相似目录、其他便携目录、不可读取路径、查询失败等七种模拟检查通过。
- 实际进程查询在系统权限下可运行。
- NSIS 安装包成功构建。
- 在隔离目录运行测试 VDRO.exe，启动静默安装器，安装器返回 1618；测试进程仍在运行，没有被终止。
- 本次未完成真实用户环境中的完整覆盖安装、迁移安装和卸载实测。

版本仍为 1.2.5，重新生成安装包。改动前的安装包另存为 release/VDRO安装程序-1.2.5-x64-before-upgrade-improvement.exe。
