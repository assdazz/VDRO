# 安装与覆盖升级

VDRO 使用 Windows x64 每用户 NSIS 安装程序。默认安装目录为 %LOCALAPPDATA%\Programs\VDRO，应用数据保存在 %APPDATA%\VDRO。卸载后保留用户数据。

## 覆盖升级

运行新版安装程序可以覆盖升级。安装器读取原有安装目录，通过 NSIS 卸载旧版本并安装新版。

安装前会检查目标目录和旧安装目录中的 VDRO.exe、ffmpeg.exe、ffprobe.exe。发现运行中的应用或媒体任务时，保存编辑内容并退出旧版，然后点击重试。取消会退出安装。

迁移安装目录时，旧目录中的运行进程也会参与检查。卸载程序使用相同的进程保护。

## 静默安装返回码

| 返回码 | 含义 |
| --- | --- |
| 1618 | 目标目录或旧安装目录中的应用或媒体任务正在运行 |
| 1603 | 无法查询进程信息 |
| 1602 | 用户取消安装 |

进程检查通过 PowerShell/CIM 查询。系统策略限制查询时，需要先处理该环境限制，再重试安装。
