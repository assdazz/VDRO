# 音频调整（方案 A）

顶部可切换“音频剪辑”和“音频调整”。两页保留当前操作状态，切换时暂停音频和视频。音频调整使用独立音频播放器，不显示或播放视频。

可直接导入音频、提取视频中的默认音轨，或在剪辑页已提取片段的“音频调整”按钮中送入片段。视频输入先转为不含视频轨道的 WAV，用于原音试听。

支持：

- ±12 半音变调，步进 0.5 半音，保持时长和速度；可保留人声共振峰。
- -24 到 +12 dB 音量调整，以及可选限幅防削波。
- 片段两端渐入和渐出，支持数值和滑块；线性、平滑和指数曲线。渐入渐出总时长不能超过片段长度。
- 波形框选、两端手柄、起止时间输入。
- 波形放大、缩小和重置缩放（1–16 倍），放大后使用底部滚动条查看其他位置。
- 音高标记：点击波形定位播放头后用“添加标记”，双击不再创建标记。点击标记数字或右侧列表选择标记后设置其音高，可编辑时间、删除单个或清除全部，最多 128 个，间隔至少 0.01 秒。
- 标记间按照半音数连续线性变化，第一个标记之前和最后一个标记之后保持该端音高。没有标记时使用基础音调。标记使用原始音频时间，改变选区不会移动标记。
- 开启“标记吸附”后，拖动框选或两端手柄，在距标记 8 个屏幕像素内吸附；可关闭吸附进行自由微调。
- 默认实时试听，可切换原音和已生成结果对比。修改参数、标记或选区自动返回实时试听。
- WAV、MP3、M4A、FLAC 输出，当前输出为 48 kHz 双声道；MP3、M4A 的“输出音质”可选 96、128、192、256、320 kbps，默认 192 kbps；WAV、FLAC 显示“无损”且禁用码率选择。
- 结果选择试听、保存和删除；相同参数可复用已生成结果。

默认实时试听：播放中修改音高、标记、音量、渐入渐出和共振峰参数直接生效，无需生成。通过 AudioWorklet 在音频线程处理，媒体流式播放，避免把整段音频解码到 JavaScript 内存。原音和已生成结果走直通路径，不重复叠加效果。

“生成保存结果”使用内置 FFmpeg 从源音频生成文件，结果可另存和试听。实时处理使用 Rubber Band R3，最终导出使用 FFmpeg 的 Rubber Band 滤镜，音色、共振峰和限幅表现可能略有差别；可点击“已生成结果”核对。实时音高处理存在短暂缓冲延迟，定位时短暂静音以避免播放上一个位置的残留声音。

原文件不被覆盖。试听和生成结果存放在应用临时提取目录，跨页面切换保留，但本版不保存调整项目供下次启动恢复；需保留的结果请另存。

实现模块：页面组合 App、原有剪辑页 ClipEditor、调整页 adjustment/AudioAdjustmentPage、IPC main/adjustment 和经过参数校验的 media/adjustmentFilters。实时试听模块为 adjustment/useRealtimePreview，使用内置 rubberband-wasm 3.3.0（GPL，发布说明见 rubberband-migration.md），支持共振峰保留。FFmpeg、wavesurfer.js 和工作线程资源均随软件分发，用户无需额外安装。

动态音高通过 FFmpeg asendcmd 向 rubberband 发送变调参数，通常每 20 毫秒更新一次；长文件最多约 60000 个采样时刻，以控制处理开销。处理选区时从该位置对应的曲线音高开始，保持输出时长。命令文件使用任务独立文件名，完成、失败或取消后清理。修改曲线后实时试听立即更新，保存修改后的音频时需重新生成结果。

验证包括：类型检查和构建、四种格式输出、升高一个八度后 330 Hz 测试音变为约 660 Hz 且时长保持、片段送入调整页、纯音频播放、渐入渐出处理、切换页面暂停以及返回页面保留结果。

标记功能验证：330 Hz 测试音按曲线升高至约 660 Hz，中间采样约 403 / 570 Hz；截取曲线中段的起始音高正确。Electron 界面验证了缩放后波形宽度、框选吸附、标记编辑和生成结果。音频剪辑的预览音量滑条与静音按钮已移至播放控制行。

本次未更新版本号、未重新打包安装程序。

界面细节：起止时间、片段时长和结果时间范围统一显示两位小数。音调、音量分别提供重置按钮，仅恢复对应参数至 0 半音、0 dB。波形上的入／出控制柄已移除，包络线与波形共用裁切范围，避免波峰超出黄色边界。

实时试听验证：在 Electron 中测量实际 Web Audio 输出，播放中调整音高后频率变化且进度持续前进；标记曲线、音量及渐入生效；双击不创建标记，点击数字正确选中；已生成结果修改参数后返回实时试听并续播；切换页面暂停播放器并挂起 AudioContext。

输出音质与格式位于“保存修改音频”按钮左侧。调整码率会生成独立结果，不会复用其他音质的缓存；无损格式保留有损码率选择，切回 MP3/M4A 时恢复。

## 共用设置与音频调整默认值

两页共用默认输出格式、音质、采样率、声道、保存方式、目录与文件名模板。默认格式和音质修改会同步到页面，页面内可临时覆盖；已有结果不变。实时试听中间文件仍采用 48 kHz 立体声，正式输出采用设置参数。原生码率会重新编码，源码率不可用时回退到 192 kbps。

“音频调整”设置包括默认保持人声共振峰（关）、默认防止音量削波（开）、默认标记吸附（开）和吸附距离（2–24 像素，默认 8）。共振峰与削波默认值在导入或恢复参数时应用；吸附默认开关在导入时应用，距离立即生效。旧设置文件自动补齐默认值。
