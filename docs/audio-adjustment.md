# 音频调整

## 项目与素材

从首页新建或打开项目，选择“音频调整”进入工作区。从顶部直接进入工作区时，编辑内容会自动保存为“未命名草稿”，可在首页恢复。

项目分别保存素材引用、轨道位置、裁剪范围、音高标记和调整参数。标题栏显示项目名与保存状态。素材文件移动或改名后，会显示在“待恢复素材”中，可以重试读取或重新定位源文件。

在素材栏点击“添加素材”导入音频或视频。导入后，将素材拖到时间线的目标位置，或选中素材后点击“添加到时间线”。视频素材读取音轨供调整使用。

## 轨道与片段

多个轨道可以同时试听并导出为一个混音文件。每个片段可独立调整起点、裁剪范围、音高、音量、渐入渐出和倒放状态。

- 拖动片段调整位置，拖动前后边缘裁剪。放置预览框显示松开后的目标位置。
- 开启吸附后，片段边缘可以对齐其他片段、播放头与音高标记。
- 轨道头提供忽略、锁定、静音和命名操作。
- 按 B 切换到分割工具，在波形上的虚线处点击即可切开。也可以直接点击工具栏的分割图标，在播放头处切开所选轨道上的片段。分割保留原有渐入渐出曲线。
- 右键片段可复制、剪切、倒放、静音或删除，轨道头的喇叭用于整轨静音。
- 时间线支持 1–32 倍缩放，通过底部滑块平移。播放头可以拖动定位。
- 每个混音最多包含 64 个片段。

## 音高与音量

音高范围为 ±12 半音，步进 0.5 半音，保持音频时长与速度。“保持人声共振峰”用于保留嗓音特点，默认关闭。

音量范围为 -24 至 +12 dB。“防止音量削波”用于控制过高的输出音量，默认开启。音高和音量各有重置按钮。

渐入、渐出提供数值与滑块控制，支持线性、平滑和指数曲线。分割后的片段保留原曲线，点击“重置渐入渐出”可清除该片段的渐变。

点击时间线工具栏的「添加标记」图标，在播放头位置创建音高标记。点击波形上的纯色长方形可选中标记，再到调整参数中修改时间和音高。悬停可查看标记名称，右键可修改名称和颜色或删除标记。相邻标记之间平滑过渡，首尾范围以外保持端点音高。每个片段最多支持 128 个标记，间隔至少 0.01 秒。

## 试听与保存

叠轨播放图标用于实时混音试听，播放所有有效的有声轨道。单个播放三角用于实时试听选中片段，可用“原音”对比。三种模式共用进度条和试听音量。播放速度菜单提供 0.5× 至 2×，倍速只作用于试听。

支持直接读取的 PCM WAV 按需读取，其他素材从播放头附近分块解码。播放中可以调整音高、音量和淡入淡出，变调处理需要短暂缓冲。试听与导出的处理路径见[音频引擎与第三方许可](audio-engine.md)。

在“调整结果”顶部选择输出格式和音质。点击“保存片段”导出选中片段，点击“保存混音”导出全部有效轨道。

- 默认输出格式为 WAV，支持 WAV、MP3、M4A 和 FLAC。
- MP3、M4A 支持 96、128、192、256、320 kbps。原生码率选项在片段导出时参考源音频码率，混音导出使用 192 kbps。
- WAV、FLAC 显示“无损”。
- 采样率、声道、保存目录和文件命名规则由共用设置控制。
- 生成结果可单独试听、保存和删除。相同素材与参数可复用已有结果。
- 生成结果保存在临时文件目录，需长期保留的文件请另存到目标目录。

## 快捷键

| 操作 | 默认快捷键 |
| --- | --- |
| 选择工具 | A |
| 分割工具 | B |
| 撤销 | Ctrl+Z |
| 重做 | Ctrl+Y 或 Ctrl+Shift+Z |
| 复制片段 | Ctrl+C |
| 剪切片段 | Ctrl+X |
| 粘贴片段 | Ctrl+V |
| 删除片段 | Delete |

输入框内使用文字编辑的撤销重做。选择与分割工具的按键可在设置中修改。
