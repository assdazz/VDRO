# VDRO 1.3.3

## 标记

- 音频剪辑与音频调整的波形标记统一为纯色竖长方形，工具栏的「添加标记」也采用相同形状。
- 新建标记按创建顺序编号。悬停可查看名称，右键可重命名、修改颜色或删除标记。
- 音频剪辑中，点击标记或拖动播放头吸附到标记后，重合处只显示一条白色播放线。缩放和平移后，播放头仍对准标记时间。
