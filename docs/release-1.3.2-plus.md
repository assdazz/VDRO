# VDRO 1.3.2+

## 试听与时间线

- 原音、单片段实时试听和实时混音按播放头附近分块读取素材。变调和音量调整可以在播放时试听。
- 三种试听共用进度与音量控件，支持 0.5× 至 2× 的试听速度。输出格式和音质集中在「调整结果」。
- 时间线可在播放头处分割所选轨道的片段。选中片段用蓝色边框标识。单片段静音可从波形右键菜单操作。

## 项目与素材

- 同一素材重复导入后，各实例独立保存标记、选区和分割。移除素材时一并清理对应编辑记录。
- 切换素材后，后台提取完成会把结果加入列表，并保持当前播放位置。移除源素材后仍可试听已生成的文件。
- 移除待恢复素材后清理空轨道残留的锁定、静音和名称。项目可从首页卡片的垃圾桶按钮删除。
