# 音频剪辑页面重新设计

页面沿用音频调整页的深色卡片、边框、间距和按钮样式，保留原有媒体处理及操作功能。

- 顶部仅保留工作页切换、当前文件信息和设置；删除额外页面标题、说明及重置布局／导入按钮行。
- 左侧为素材列表，右侧主工作区按视频预览、波形剪辑、提取结果排列。
- 输出格式与音质位于已提取音频栏内；素材列表保留添加、移除、切换、排序及收起功能。
- 视频和音频播放、预览选区、循环、音量、波形缩放、选区手柄及时间点设置继续可用。
- 已提取结果的播放、保存、删除、送入音频调整保留，按钮样式统一。
- 原有面板折叠、分隔条拖动、快捷键、设置及导出取消继续使用原有逻辑。
- 布局存储更新为 v2，首次使用新布局会重置旧版面板尺寸；不删除素材或已提取文件。

新视觉规则集中在 clip-editor.css，仅作用于剪辑页。调整页不受影响。

本轮检查：类型检查、构建、空状态和载入状态截图、素材载入、结果栏内格式选择、音频提取，以及 100% / 125% 缩放下折叠和分隔条极限拖动。未更新版本号或重新生成安装程序。

视觉细化：保持素材左栏、输出设置位于提取结果栏的当前布局。卡片、列表项与控件采用统一圆角；播放条改为圆润底板及圆形播放按钮；片段时间使用独立圆角数值卡；统一中性边框、悬停和键盘焦点样式。本轮只修改剪辑页样式，不修改处理和交互逻辑。
