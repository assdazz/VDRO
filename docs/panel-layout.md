# 面板拖动边界

视频预览折叠后，上方容器仍必须容纳 60px 的视频折叠栏和 268px 的音频预览，最小高度为 328px。音频预览也折叠时，其占用高度为 48px。

此前折叠视频后容器最小高度为 0，拖动已提取音频的分隔条会把容器挤得比内部音频预览更矮，造成底部播放控件被裁切或遮挡。

现在容器的最小高度统一按两个预览面板的折叠状态计算，并在已提取音频拖动比例上限中预留相应空间。固定高度和比例布局使用同一高度下限，避免拖动开始时从固定尺寸切回比例布局而丢失限制。

验证：使用隔离用户目录，在 100% 和 125% 界面缩放下折叠视频预览，将已提取音频分隔条分别拖至窗口顶部、底部，再拖至顶部。两种缩放下音频预览均保留至少 268px，底部播放控件始终位于已提取音频面板上方，面板间保留分隔空间。

## 两个预览折叠后的底部拖动条

只展开已提取音频时，其最大高度按可视窗口底边、面板实际顶部、下方拖动条及其他兄弟元素所占空间计算，预留外边距和底部空隙。拖动条不能移出窗口；恢复过大的保存高度及窗口缩小时会重新限制高度。

两个折叠栏固定占 108px，关闭其高度过渡，避免残留展开尺寸。只展开已提取音频时取消主列在高缩放下的 700px 最小高度，并关闭该面板尺寸过渡，确保边界限制立即生效。

隔离窗口测试：100% / 125% 缩放下拖至底部、重新向上拖动、再次拖至底部，以及缩小到 1200×720 后触发页面 resize，拖动条均保持在可视范围。隐藏测试窗口的 resize 事件通过测试脚本显式发送。
